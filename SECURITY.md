# Security

Do not include API keys, credentials, private source code, or personal data in
issues, pull requests, fixtures, or recorded operations. Operation logs and
commit messages can contain source text and paths; review them before pushing.

Report vulnerabilities privately through GitHub's **Security → Report a
vulnerability** when available. If private reporting is unavailable, open an
issue requesting a private reporting channel without including exploit details
or sensitive data.

This tool edits files and creates Git commits. Review merge results and run your
project's checks before publishing them. Keep a clean checkout or backup before
trying new merge or rebase workflows.
